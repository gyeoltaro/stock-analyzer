# stock-analyzer

한국 주식(KOSPI·KOSDAQ)을 **정해진 규칙**으로 점수 매겨 순위를 보여주는 도구입니다.
감이나 예측이 아니라, 학계에서 오래 연구된 팩터(모멘텀·가치·저변동성)를 단순하게 결합합니다.

> ⚠️ 참고용 도구입니다. 투자 권유가 아니며 미래 수익을 보장하지 않습니다.
> 과거에 통한 규칙이 앞으로도 통한다는 보장은 없습니다. 투자 판단과 손실 책임은 본인에게 있습니다.

## 동작 방식

1. **유니버스**: 시가총액 상위 N개 보통주 (우선주·스팩·리츠, 거래대금 10억 미만 제외)
2. **필터**: 종가 > 120일 이동평균(상승 추세), RSI(14) < 75(과열 제외), 1년 이상 거래 이력
3. **점수(0~100)**: 아래 항목의 백분위 가중합

   | 팩터 | 비중 | 의미 |
   |---|---:|---|
   | 12-1개월 모멘텀 | 35% | 최근 1개월을 뺀 1년 수익률 |
   | 3개월 모멘텀 | 15% | 최근 3개월 수익률 |
   | 가치 | 25% | 이익수익률(1/PER)·1/PBR (적자·자본잠식 제외) |
   | 저변동성 | 25% | 60일 변동성이 낮을수록 높음 |

4. **백테스트**: 매월 말 상위 20개를 동일 비중으로 리밸런싱, 매매비용 0.3% 차감, KOSPI200과 비교

## 데이터 소스

| 소스 | 필요한 것 | 특징 |
|---|---|---|
| **네이버 금융 (기본)** | 없음 | 회원가입 불필요. 비공식 경로라 네이버가 페이지를 바꾸면 멈출 수 있음. 과거 PER/PBR이 없어 백테스트에서는 가치 팩터 제외 |
| KRX (pykrx) | data.krx.co.kr **일반 회원** 아이디/비밀번호 (카카오 로그인 불가) | 거래소 공식 데이터. 과거 PER/PBR 포함 |

`KRX_ID`, `KRX_PW` 환경 변수가 있으면 KRX, 없으면 네이버를 씁니다. `DATA_SOURCE=naver` 로 강제할 수 있습니다.

```bash
pip install -r requirements.txt
```

## 사용법

```bash
python main.py report              # 오늘의 점수 리포트 → reports/YYYY-MM-DD.md, reports/latest.md
python main.py backtest --years 5  # 백테스트 → reports/backtest.md
python -m pytest -q                # 오프라인 테스트
```

## 매일 자동 실행 (GitHub Actions)

평일 16:40(KST)에 리포트를 만들어 `reports/`에 커밋합니다. 기본은 네이버 데이터라 따로 설정할 것이 없습니다.
KRX 데이터를 쓰려면 **Settings → Secrets and variables → Actions**에 `KRX_ID`, `KRX_PW`를 등록하세요.
Actions 탭에서 `daily-report`를 수동 실행할 수도 있습니다 (`backtest` 입력 가능).

## 알려진 한계

- **생존편향**: 백테스트 유니버스를 현재 시총 상위로 잡아 과거 성과가 부풀려집니다.
- 펀더멘털(PER/PBR)은 후행 지표입니다. 네이버 소스에서 PBR은 PER × ROE / 100 으로 계산합니다.
- 거래정지·상장폐지 종목은 수익률 0%로 처리됩니다.
